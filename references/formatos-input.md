# Referências de Formatos — Input Manual

> Este arquivo é alimentado pelo Robson (ou qualquer pessoa) quando vê um formato de post
> que chama atenção no Instagram. O Radar consulta isso nas execuções.

---

## Como Adicionar

Copie o template abaixo, preencha e mande pro Dexter:

```
---FORMATO---
perfil: @nomedoperfil
link: (URL do post, se tiver)
tipo: carrossel | estatico | story | reel
formato: (ex: "dado gigante", "antes/depois", "checklist", "comparativo")
descricao: (1-2 linhas do que vc vz)
porque_funciona: (o que chama atencao)
momento: (onde vc viu — feed, story, explorar)
---FIM---
```
